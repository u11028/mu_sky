# MU Sky

เกม RPG ออนไลน์ 3 มิติ ตัวละครชิบิน่ารัก เล่นได้ทั้งบนเว็บและมือถือ ผจญภัยใน 6 ภาคของไทย ตีมอนสเตอร์ ล่าบอส สู้กับผู้เล่นอื่น สะสมฉายา และทำภารกิจประจำวัน

## ต้องมี

- Node.js 22 ขึ้นไป

## เริ่มเล่น

```bash
npm install
npm run build
npm start
```

เปิด http://localhost:2567 ในเบราว์เซอร์ มือถือที่ต่อ Wi-Fi เดียวกันเข้าได้ที่ `http://<IP ของคอม>:2567`
(ครั้งแรก Windows อาจถามเรื่อง Firewall ให้กดอนุญาต)

## ระหว่างพัฒนา

```bash
npm run dev
```

เปิด http://localhost:5173 แก้โค้ดแล้วหน้าเกมโหลดใหม่เอง ส่วนเซิร์ฟเวอร์ (พอร์ต 2567) รีสตาร์ทเอง

## วิธีเล่น

| | คอม | มือถือ |
|---|---|---|
| เดิน | WASD หรือลูกศร หรือคลิกพื้น | จอยสติ๊กซ้ายล่าง หรือแตะพื้น |
| ซูมกล้อง | ลูกกลิ้งเมาส์ | ใช้สองนิ้วถ่างหรือหุบ |
| โจมตี | Space หรือ J | ปุ่มแดง ⚔ |
| ฟันพายุหมุน (ตีรอบตัว) | Q หรือ 1 | ปุ่ม 🌀 |
| พุ่งทะยาน | E หรือ 2 | ปุ่ม 💨 |
| ฟาดสายฟ้า (ตีหนักข้างหน้า) | R หรือ 3 | ปุ่ม ⚡ |
| พรแห่งชีวิต (ฮีลตัวเอง) | F หรือ 4 | ปุ่ม 💚 |
| แชท | Enter พิมพ์ แล้ว Enter ส่ง | แตะช่องพิมพ์ |
| ภารกิจและฉายา | ปุ่ม 📜 มุมซ้ายบน | เหมือนกัน |

- **6 ภาค** เดินเข้าประตูวาร์ปเพื่อเดินทาง แต่ละภาคมีมอนสเตอร์ของตัวเองและบอส 1 ตัว ยิ่งไกลจากภาคกลางยิ่งเก่ง
- **ต่อสู้** ตีได้ทั้งมอนสเตอร์และผู้เล่นอื่น ล้มแล้วได้ XP เลเวลอัพแล้วเลือดและพลังโจมตีเพิ่ม ถูกล้มแล้วฟื้นใน 5 วินาที
- **ภารกิจประจำวัน** 5 ข้อ เปลี่ยนใหม่ทุกเที่ยงคืนเวลาไทย
- **ฉายา** 26 แบบ ตั้งแต่ธรรมดาจนถึงระดับเพี้ยนระดับตำนาน แสดงบนหัวและเปลี่ยนกรอบแชต
- **ห้อง** เลือกได้ในหน้าเข้าเกม: 🌏 ห้องรวม (เจอทุกคน) · 🔒 สร้างห้องส่วนตัว (ได้รหัส 6 ตัว กด "ชวนเพื่อน" เพื่อส่งลิงก์) · 🔑 เข้าห้องเพื่อนด้วยรหัส ห้องส่วนตัวมีมอนสเตอร์และบอสของตัวเอง เดินข้ามภาคก็ยังอยู่ด้วยกัน
- **อาชีพ** แต่ละตัวละครสู้ต่างกัน: อัศวินเลือดเยอะ นักรบเถื่อนตีแรง โจรตีไว พรานป่ายิงธนู นักฆ่าคลุมหน้ายิงหน้าไม้ จอมเวทยิงลูกเวท กดโจมตีแล้วจะหันหามอนสเตอร์ใกล้สุดเอง
- **ทองและร้านค้า 🛒** มอนสเตอร์ดรอปทอง (บอสให้เยอะ) ซื้อยาเลือด อาวุธ 5 ขั้น (เรืองแสงตามขั้น) และเกราะ 5 ขั้น
- **ยาเลือด 🧪** ปุ่มเหนือสกิล หรือกด G / 5 ฟื้นเลือด 50%
- **ปีก 🪽** 6 แบบในร้านค้า: นางฟ้า ปีศาจ ผีเสื้อแสงจันทร์ ฟีนิกซ์เพลิง มังกรมรกต เทพจักรวาล กระพือตามจังหวะ เพิ่มพลังโจมตีสูงสุด ×1.3
- **สัตว์ขี่ 🐎** 6 ตัวในร้านค้า: ม้า กวาง หมาป่า ม้าขาว แร็พเตอร์ มังกร (บินได้) กดปุ่ม 🐎 ข้างจอยสติ๊ก หรือกด V เพื่อขึ้นลง วิ่งเร็วสูงสุด ×1.85 โจมตีเมื่อไหร่จะลงจากหลังเอง
- **ทีม 👥** ชวนผู้เล่นในภาคเดียวกันเข้าทีม (สูงสุด 4 คน) แบ่ง XP และทอง ตีกันเองไม่โดน เห็นเลือดเพื่อนที่มุมจอ
- **ตั้งค่า ⚙** เปิดปิดเพลงและเสียง ปรับคุณภาพกราฟิก (เครื่องกระตุกให้เลือก "ประหยัด") แต่ละภาคมีเพลงของตัวเอง ใกล้บอสเปลี่ยนเป็นเพลงต่อสู้
- **บัญชี** สมัครในหน้าเข้าเกม (หัวข้อ "บัญชี") แล้วเข้าสู่ระบบจากเครื่องไหนก็ได้ เลเวล ฉายา และภารกิจจะตามไปด้วย

## เปิดให้เล่นออนไลน์ผ่าน GitHub Codespaces (ฟรีตามโควตา GitHub)

1. ในหน้า repo บน GitHub กดปุ่มเขียว **Code → Codespaces → Create codespace on master**
2. รอสักครู่ เกมจะ build และเปิดเซิร์ฟเวอร์เอง
3. ไปที่แท็บ **Ports** คลิกขวาที่พอร์ต 2567 → **Port Visibility → Public**
4. คัดลอกลิงก์ในช่อง Forwarded Address ส่งให้เพื่อน

Codespace จะหยุดเองเมื่อไม่มีการใช้งานสักพัก (ค่าเริ่มต้น 30 นาที) และข้อมูลผู้เล่นอยู่ในตัว codespace นั้น

## เปิดให้เล่นออนไลน์ (Render)

ไฟล์ `render.yaml` เตรียมไว้แล้ว ทำครั้งเดียว:

1. สมัคร https://render.com ด้วยบัญชี GitHub
2. กด **New → Blueprint** แล้วเลือก repo `mu_sky`
3. ใส่ `GM_KEY` (รหัส GM ที่จะใช้พิมพ์ `/gm <รหัส>` ในเกม) แล้วกด **Apply**
4. รอ build เสร็จ จะได้ลิงก์ `https://mu-sky-xxxx.onrender.com` ส่งให้เพื่อนเล่นได้เลย

ตอนนี้ตั้งเป็นแผน `free` (ไม่ต้องผูกบัตร) ข้อเสียคือเซิร์ฟเวอร์จะหลับเมื่อไม่มีคนเล่นสักพัก และข้อมูลผู้เล่นจะเริ่มใหม่ทุกครั้งที่เซิร์ฟเวอร์รีสตาร์ท
ถ้าอยากเก็บข้อมูลถาวร เปลี่ยนเป็นแผน `starter` พร้อมดิสก์ตามที่เขียนไว้ใน `render.yaml` (ต้องผูกบัตร มีค่าบริการรายเดือน)
ทุกครั้งที่ push ขึ้น GitHub Render จะอัปเดตเกมให้เอง

## GM (ผู้ดูแลเกม)

ครั้งแรกที่รันเซิร์ฟเวอร์ จะสร้างรหัส GM แบบสุ่มไว้ที่ `server/data/gm-key.txt` (ไม่ถูกส่งขึ้น Git)
ในเกม พิมพ์ในแชทว่า `/gm <รหัส>` ครั้งเดียว ผู้เล่นนั้นจะเป็น GM ตลอด แล้วกดปุ่ม 🛡 GM เพื่อเปิดแผงควบคุม:
ฆ่า ฟื้นพลัง อมตะ ฆ่าทีเดียวตาย เพิ่มหรือลดเลเวล มอบฉายา วาร์ปไปหา ดึงมาหา เตะออก แบน (กี่วันหรือถาวร) ปลดแบน และประกาศถึงทุกภาค

จะตั้งรหัสเองก็ได้ด้วยตัวแปร `GM_KEY` ตอนรันเซิร์ฟเวอร์

## ข้อมูลที่เซิร์ฟเวอร์เก็บ

อยู่ใน `server/data/` (ไม่ถูกส่งขึ้น Git) หรือในโฟลเดอร์ที่ตั้งด้วยตัวแปร `DATA_DIR` สำรองโฟลเดอร์นี้ไว้ถ้าย้ายเครื่อง

| ไฟล์ | มีอะไร |
|---|---|
| `progress.json` | เลเวล ภารกิจ ฉายา สถานะ GM และการแบนของผู้เล่นทุกคน |
| `accounts.json` | ชื่อบัญชีและรหัสผ่าน (เก็บเป็นค่าแฮช scrypt ไม่ใช่รหัสจริง) |
| `gm-key.txt` | รหัส GM |

## โครงสร้าง

| โฟลเดอร์ | มีอะไร |
|---|---|
| `server/` | เซิร์ฟเวอร์ Colyseus: ห้องละภาค คุมการเดิน การต่อสู้ มอนสเตอร์ แชท ภารกิจ GM และบัญชี |
| `client/` | ตัวเกม 3 มิติ (Three.js) + หน้าจอ HTML (แชท ภารกิจ แผง GM ปุ่มต่อสู้) |
| `shared/` | กติกาที่ทั้งสองฝั่งต้องตรงกัน: ภาค แผนผังฉาก มอนสเตอร์ สกิล ฉายา ภารกิจ |

เซิร์ฟเวอร์เป็นตัวตัดสินทุกอย่าง ทั้งตำแหน่ง ดาเมจ และรางวัล ตัวเกมส่งแค่ปุ่มที่กด จึงโกงไม่ได้
