# MU Sky

เกม RPG ออนไลน์ 2D เล่นได้ทั้งบนเว็บและมือถือ ตอนนี้อยู่ขั้นที่ 1 (ต้นแบบ): ผู้เล่นหลายคนเดินในแผนที่เดียวกันและแชทคุยกันได้

## ต้องมี

- Node.js 22 ขึ้นไป

## เริ่มเล่น

```bash
npm install
npm run build
npm start
```

เปิด http://localhost:2567 ในเบราว์เซอร์ มือถือที่ต่อ Wi-Fi เดียวกันเข้าได้ที่ `http://<IP ของคอม>:2567`
(ครั้งแรก Windows อาจถามเรื่อง Firewall ให้กดอนุญาต)

## ระหว่างพัฒนา

```bash
npm run dev
```

เปิด http://localhost:5173 แก้โค้ดแล้วหน้าเกมโหลดใหม่เอง ส่วนเซิร์ฟเวอร์ (พอร์ต 2567) รีสตาร์ทเอง

## วิธีเล่น

| | คอม | มือถือ |
|---|---|---|
| เดิน | WASD หรือลูกศร หรือคลิกพื้น | แตะพื้น |
| แชท | Enter พิมพ์ แล้ว Enter ส่ง | แตะช่องพิมพ์ |

## โครงสร้าง

| โฟลเดอร์ | มีอะไร |
|---|---|
| `server/` | เซิร์ฟเวอร์ Colyseus: ห้อง `world` คุมตำแหน่งผู้เล่นและแชท |
| `client/` | ตัวเกม Phaser 3 + หน้าแชท HTML |
| `shared/` | ค่าที่ทั้งสองฝั่งต้องตรงกัน เช่น ขนาดแผนที่ ความเร็วเดิน |

เซิร์ฟเวอร์เป็นตัวคำนวณตำแหน่งทุกอย่าง ตัวเกมส่งแค่ปุ่มที่กดหรือจุดที่แตะ จึงโกงความเร็วไม่ได้
